One-line: the standard Arko surface — use for step cards, service cards, testimonial shells and form panels.

```jsx
<Card variant="raised" interactive>
  <h3>Blindagem patrimonial</h3>
  <p>Proteja o que você construiu.</p>
</Card>
```

Radius 14px, 1px `--border-subtle`, `--shadow-sm`. Never add a colored left border.
