One-line: every Arko section starts with this trio — overline, title, lead.

```jsx
<SectionHeading overline="Método Arko" title={<>Como será sua jornada para <strong>mudar sua vida financeira.</strong></>}
  lead="Seis etapas, executadas ao seu lado, com um consultor exclusivo." />
```

Titles end in a period, as on the live site. Use `onDark` inside navy bands.
